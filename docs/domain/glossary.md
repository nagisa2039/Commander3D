# 用語集

コード上の識別子(英語)と日本語の対応。用語を追加・変更したらここを更新する。

| 識別子 | 日本語 | 説明 |
|---|---|---|
| `Battle` | 戦闘(マップ戦) | 1マップ分の状態。Aggregate Root |
| `BattleUnit` | 戦闘ユニット | マップ上のキャラクター。Entity |
| `GridCoord` | グリッド座標 | マス目の位置。Value Object |
| `UnitId` | ユニットID | `BattleUnit` の識別子 |
| `Faction` | 陣営 | `Player` / `Enemy`。敵陣営ユニットは移動を阻む |
| `MovementRange` | 移動範囲 | ユニットが到達できるマスと最小コスト・経路。通過できても止まれないマスがある |
| `UnitMoved` | ユニット移動イベント | 移動経路(開始〜終了)を持つ Event |
| `UnitWaited` | 待機イベント | ユニットが行動を終えた事実 |
| `PhaseChanged` | フェーズ切替イベント | 新しいフェーズの陣営とターン番号。敵→自軍でターンが進む |
| `WeaponSpec` | 武器仕様 | 威力・命中・射程(最小/最大)。最大射程0は武器なし |
| `IRandomSource` | 乱数源 | 命中判定用 0〜99 の乱数。テストでは固定値を差し込む |
| `Strike` | 一撃 | 攻撃または反撃の1回分(命中有無・ダメージ・被弾後HP) |
| `AttackResolved` | 攻撃結果イベント | 攻撃と反撃の `Strike` 列と撃破されたユニット |
| `BattleOutcome` | 戦闘結果 | `Ongoing` / `PlayerWon` / `PlayerLost` |
| `VictoryConditions` | 勝利条件設定 | 殲滅(既定)・ボス撃破・ターン制限(超過で敗北)。自軍全滅は常に敗北 |
| `BattleSetup` | 戦闘セットアップ | マップ・ユニット配置・勝利条件。`StartBattle` が検証して `Battle` にする |
| `BattleSession` | 戦闘セッション | Command を受けて Event を返す唯一の窓口 |
| `StdRandomSource` | 標準乱数源 | シード指定可能な本番用 `IRandomSource` |
| `DecideNext` | 敵AIの次手決定 | 敵フェーズで次に出す Command を返す。プレイヤーと同じ Command 経路を使う |
| `RunEnemyPhase` | 敵フェーズ実行 | `DecideNext` を繰り返し、フェーズ終了まで Event 列を返す |
| `Durability` | 武器耐久 | 武器の最大使用回数。0 は壊れない。一撃ごと(命中・ミス問わず)に1消費し、0で壊れて攻撃・反撃できなくなる |
| `Level` / `Experience` | レベル / 経験値 | レベル1〜20、経験値100で1上がる。経験値を得るのは戦闘に参加して生き残った自軍ユニットのみ |
| `GrowthRates` | 成長率 | レベルアップ時に各能力が+1される確率(%)。クラスから受け継ぐ |
| `LevelUp` / `ExperienceGained` | レベルアップ / 経験値獲得イベント | `AttackResolved` に含まれる |
| `ItemSlot` / `ItemKind` | 所持品スロット / 種別 | 最大5。予備の武器・薬(回復)・修理キット |
| `EquipWeapon` | 武器の持ち替え | 装備中の武器と所持品の武器を交換する。行動を消費しない |
| `UseItem` | アイテム使用 | 薬の回復・修理キットによる武器耐久の全回復。行動を消費する |
| `GiveItem` / `DropItem` | アイテムを渡す / 捨てる | 渡すのは隣接する同陣営のユニットへ(行動消費)。捨てるのは行動を消費しない |
| `Staff` / `UseStaff` | 杖 / 杖の使用 | 射程内の味方を回復する所持品。使用で行動終了、回数が尽きると消える |
| `Shop` / `Gold` | 店 / 所持金 | 店マスに立つ自軍ユニットが購入・売却(売値は半額、行動は消費しない)。所持金は軍単位 |
| `StatCaps` | 能力上限 | レベルアップでこれ以上は上がらない値。0は上限なし |
| `PromotionSpec` / `PromoteUnit` | クラスチェンジ | 昇格先を複数持てる(最大4)。選んだ1つの条件レベルで1回だけ。ボーナス加算、Lv1に戻り、成長率と上限が新クラスのものになる |
| `PromotionSeal` | 昇格アイテム | 使うと、昇格先の条件レベルに満たなくても、アイテム側のレベル以上なら昇格できる。回数を1消費 |
| `Avoid` / `RankHit` / `RankAvoid` | 回避・ランクごとの命中/回避ボーナス | 武器の補正。相手の命中率から回避を引き、使い手のランクごとに命中・回避が増える。壊れた武器の補正は効かない |
| 敵の回復役 | ヒーラー(敵) | 杖で味方を回復する。回復量の割合が低い味方を優先。武器がなければ傷ついた味方に付いていく。敵は薬・修理キットは使わない |
| `WeaponSpec::Type` / `RequiredRank` | 武器種別 / 必要ランク | ユニットの種別ごとの熟練度(使用回数)からランク0〜3が決まり、足りない武器は使えず装備もできない |
| `Roster` | 部隊名簿 | 戦闘をまたいで残る自軍のキャラ(レベル・経験値・持ち物・熟練度)と所持金。HPは戦闘後に全回復。戦闘外で装備替え・受け渡し・捨てるができる |
| `Difficulty` | 難易度 | `Classic`は戦死したキャラを失う、`Casual`は次章で戦闘前の状態に戻る |
| `Preparation` | 準備(身支度) | 戦闘前に出撃者(出撃マス数まで)を選び、持ち物を整えて戦闘を開始する。結果は`Finish`でRosterに戻す |
| `Chest` / `OpenChest` | 宝箱 | マス上の宝箱。自軍ユニットがそのマスに立って開けると、アイテム(持ち物へ)か所持金のどちらか一つが手に入る。行動を消費し、宝箱は消える。持ち物が満杯だとアイテム入りは開けられない |
| `Campaign` / `Chapter` | キャンペーン / 章 | 章の並びと進行。勝利で次章へ、敗北は同じ章をやり直す。途中の章からの再開(セーブ)に対応 |
| `Phase` | フェーズ | 自軍・敵軍など、陣営ごとの行動順の区間 |
| `Command` | コマンド | プレイヤー/AIの意図(`MoveUnit` など) |
| `Event` | イベント | Domainが返す、起きた事実。Presentationが再生する |

(以降、設計の進行に合わせて追記する)
